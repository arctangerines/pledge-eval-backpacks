# XgFabric
XgFabric us a fluid simulation and ML pipeline
designed to consume real-time sensor data from agricultural sites and simulate projected weather.

## Executing
Run the backpack with:
```
floability execute --backpack .
```

## XgFabric reference

Vuran, and Rich Wolski. xGFabric: Coupling Sensor Networks and HPC Facilities with Private 5G Wireless Networks for Real-Time Digital Agriculture. In Workshop on Extreme-Scale Experiment-in-the-Loop Computing (XLOOP) at Supercomputing, 2025.`
